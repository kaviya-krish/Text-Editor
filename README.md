# Smart Text Editor

A desktop-based Text Editor developed using Java Swing with useful editing and customization features.

---

## 📸 Project Preview

### Main Editor Window
![Editor Screenshot](TextEditor.png)

---

## ✨ Features
- Create New Files
- Open Existing Text Files
- Save Text Files
- Cut, Copy, Paste Operations
- Search Functionality
- Random Theme Generator
- Live Word Count
- Live Character Count
- Scroll Support
- User-Friendly GUI

---

## 🛠️ Technologies Used
- Java
- Java Swing
- AWT
- File Handling
- Event Handling

---

## 📂 Project Structure

```text
TextEditor/
└── src/
    ├── app/
    │    └── Main.java
    ├── ui/
    │    └── EditorFrame.java
    ├── util/
    │    └── FileManager.java
```

---

## ▶️ How to Run

### Compile
```bash
javac -d out src/app/Main.java src/ui/EditorFrame.java src/util/FileManager.java
```

### Run
```bash
java -cp out app.Main
```
